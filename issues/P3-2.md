Level stays P3. Also reported here, not edited into the generated file: `ISSUES.md` claims "no test for isRunning() with invalid PID values", but `tests/BackgroundJobTest.php:517-523` (`testIsRunningReturnsFalseForInvalidPid`, exercising 0, -1 and 99999999) has existed since the initial commit `ca54c60`; and it claims "no test for wait() timeout behavior", yet this module exposes no `wait()` method at all.
